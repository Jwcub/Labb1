# Laboration 1 - Fullstackutveckling med ramverk

I den här laborationen prövar jag två CSS-ramverk (Bootstrap och Tailwind). Jag skapade en enkel sidstruktur utan ramverk som jag ungefär återskapade med de två olika ramverken. Jag har även skapat eller använt komponenter såsom tabeller och formuär. På varje undersida beskrivs ramverken i korthet samt mina tankar om ramverken och arbetsprocessen.
