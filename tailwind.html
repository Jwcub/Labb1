Tailwind CSS

Tailwind CSS är ett gratis open-source ramverk för CSS. Tailwind består, till skillnad från många andra ramverk, inte av på förhand definerade komponenter såsom menyer, knappar och tabeller. Istället bygger Tailwind på att skapa en lista med hjälpklasser som kan kombineras för att uppnå önskat utseende. Detta resulterar i att den mesta av CSS-utvecklingen sker i HTML-dokumentet. (Wikipedia, 2026)

Utveckling i Tailwind CSS (mina erfarenheter)

Jag tycker att Tailwind CSS har en tydlig och lättläst dokumentation. Ramverket har en annorlunda installationsmetod där man installerar en CLI, men instruktionerna är väldigt tydliga och enkla att följa. Jag valde dessutom att installera Tailwind CSS IntelliSense samt Tailwinds tillägg för Prettier för ännu enklare utveckling i ramverket. Det tar ett tag innan man lär sig klasserna, men har man dokumentationen öppen så funkar sökfunktionen väldigt bra för att få fram klassnamn. Generellt tycker jag att utvecklingen är Tailwind är smidig. Det som är negativt är att man inte får något gratis. Man behöver styla alla element. Jag tycker också att det kan bli mycket repetitivt, där vissa koder behöver skrivas in flera gånger. Det som dock verkar väldigt smidigt är att man kan skapa egna klasser i CSS-filen, så vill jag återanvända samma CSS till flera element kan jag bara ange den egna klassen.
